# Archive

This directory holds stale plans, PRDs, and knowledge artifacts from earlier iterations of serf. They are preserved for reference but are not part of the active v1.0.0 system.

## Contents

- `plans/` — old design plans for features that were not fully implemented:
  - `living-critic-architecture.md`
  - `worktree-isolation-plan.md`
  - `interactive-task-intake-plan.md`
  - `multi-provider-llm-plan.md`
- `memory/` — PRDs and research notes from earlier architecture explorations.
- `knowledge_base/` — old task board from a previous harness iteration.

These documents describe architectures (TUI, watchdog, event bus, domain/infrastructure split) that do not exist in the current codebase. If a concept here is needed again, it should be re-derived from the current code rather than resurrected verbatim.
